# ShiftSync

An Android app for employee shift scheduling and workforce management, built in Java with Firebase.

## Demo Video

## Features

- **Authentication** – Secure registration and login with Firebase Authentication
- **Shift management** – Managers create shifts; employees view their schedule
- **Self-scheduling** – Employees browse open shifts and sign up for them
- **Assignments** – Track which employee is assigned to which shift
- **Payslip generation** – Automatic payslip calculation based on worked shifts
- **Multi-organization support** – A group-code system scopes data to each organization

## Tech Stack

- **Language:** Java
- **Platform:** Android (Fragments, RecyclerView)
- **Navigation:** Android Navigation Component
- **Backend:** Firebase Authentication, Firebase Realtime Database
- **Build:** Gradle (Kotlin DSL)


## Getting Started

1. Clone the repository
2. Open the project in Android Studio
3. Create a Firebase project and add an Android app with the package name `com.example.shiftsyncproject`
4. Download `google-services.json` and place it in the `app/` folder
5. Enable Email/Password authentication and Realtime Database in the Firebase console
6. Build and run
